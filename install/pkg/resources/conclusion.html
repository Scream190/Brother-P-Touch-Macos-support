Driver installed

Next step: connect the printer via USB, power it on, then open System Settings → Printers & Scanners → Add Printer (+). Select the matching Brother entry from the list (or, if it isn't detected automatically, choose "Select Software..." and search for "Brother PT-P710BT", "Brother PT-P700", or "Brother PT-P750W").

In the Print dialog, pick the Tape Width matching your loaded cassette, and use "Manage Custom Sizes..." in the Paper Size menu for a specific label length.

See the project's README.md (in the folder you downloaded this installer from) for troubleshooting, Bluetooth notes, and the standalone command-line tools for hardware bring-up and media detection.
