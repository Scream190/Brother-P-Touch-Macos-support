Brother PT-P710BT / PT-P700 / PT-P750W macOS Driver

Unofficial, community-written. Not affiliated with or endorsed by Brother Industries, Ltd.

This installs the CUPS filters, backend, and PPDs needed to print to a Brother PT-P710BT, PT-P700, or PT-P750W label printer from any macOS application's normal Print dialog. (Only the PT-P710BT is confirmed on real hardware so far -- see the project's README.md.)

After installing, connect the printer via USB and add it in System Settings → Printers & Scanners → Add Printer — no Terminal needed.
